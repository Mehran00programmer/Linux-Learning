# آموزش لینوکس (Linux Learning)

### معرفی پروژه
این مخزن یک مرجع فارسی، منظم و پروژه‌محور برای یادگیری **لینوکس** از سطح مبتدی تا پیشرفته است. هدف، ارائه مسیری گام‌به‌گام برای درک مفاهیم سیستم‌عامل، خط فرمان، مدیریت سیستم و آماده‌سازی برای نقش‌های DevOps و مدیریت سرور است.

### پیش‌نیازهای آموزش
- آشنایی مقدماتی با کامپیوتر و مفاهیم فایل و پوشه
- (اختیاری) آشنایی با یک زبان برنامه‌نویسی مثل Python یا Bash
- دسترسی به یک محیط لینوکس (ماشین مجازی، WSL، یا سرور ابری)

---

### موضوعات این مخزن
- مبانی لینوکس و ساختار فایل‌سیستم
- دستورات خط فرمان و ناوبری
- مجوزهای فایل و مدیریت کاربران
- مدیریت بسته‌ها و نرم‌افزار
- مدیریت فرآیندها و سرویس‌ها (systemd)
- شبکه و SSH
- اسکریپت‌نویسی Bash
- مدیریت سرور و کانتینرها (Docker)
